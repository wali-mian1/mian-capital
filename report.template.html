Mian Capital

A values-aware investing research assistant and portfolio evidence view for people who want their financial choices to reflect Islamic principles.

Student: Wali Mian · Yale School of Management

01 / Motivation

A specific gap in an important decision

A faith-conscious investor often has to answer two questions at once: “What does this investment do?” and “Does it fit my constraints?”

The user

Community members who avoid activities such as alcohol and gambling and want an understandable starting point for Shariah-oriented investing. A second user is a newly high-earning professional who has not yet opened a brokerage account.

Current workflow

Search a fund name, find its ticker, open a price page, locate the issuer's screening statement, check recent news, and manually compare holdings. Many sources mix strategy claims with investment marketing.

Where time and trust are lost

Names and tickers are easy to confuse; a name passed to a market-data API can return nothing. A fund's Islamic label also does not establish that every current underlying holding passes one chosen screening method. Different screens may use different sector and financial-ratio thresholds. A single unexplained “compliant” badge hides those distinctions.

Mian Capital gives one place to ask a research question, inspect tool inputs and outputs, see dated source links, and put a simple portfolio into an evidence view. It deliberately keeps unknown positions visible. The account setup page addresses a separate first step: explaining brokerage choices and mechanics while the visitor keeps control of credentials and trades.

Figure 2. Founder bio and brokerage education flow.

Why this is a real need: The founder has eight years of personal investing experience and four years of actuarial work in retirement and benefits. Those qualifications inform the problem framing; this project does not claim a measured market size or a verified financial return for users.

02 / Novelty

Where the app fits among existing products

Zoya and Musaffa already offer Islamic investing research and screening tools. Wahed offers Shariah-oriented investment products. These are meaningful comparators, not empty stand-ins. Mian Capital's current differentiator is a local, inspectable research conversation tied to a human advisor's education flow and an explicit unknown share in the portfolio result.

What is new here

  1. Inspectable agent steps: The chat displays each yfinance price call or native web search call with input and output. “Amana Growth Fund” is resolved to AMAGX before the price tool runs.
  2. Evidence coverage, not a false badge: The portfolio view calculates the share of entered market value in funds with a checked issuer screening description. Unsupported or unverified entries remain “needs review.”
  3. Learning before action: The Paper Lab contrasts historical adjusted-close experience with a user-assumed future compound-growth scenario and labels the two differently.

03 / Agent design

One bounded research agent; deterministic calculators

The PydanticAI agent answers chat questions. The model is gpt-6-luna through Portkey's OpenAI-compatible Responses API, following the course key rule. It selects between exactly two capabilities. Portfolio arithmetic and paper-money scenarios are Python functions outside the model so their numbers are repeatable.

Price tool

get_stock_price(ticker,start,stop) accepts one of eight supported tickers, validates dates and an exclusive stop date, and returns dated Yahoo closes and a source URL. Name aliases resolve before the call.

Web search

OpenAI native web_search handles recent news and current issuer claims. The app exposes returned URLs; external pages are treated as untrusted data.

Other product components

Portfolio evidence calculator: parses up to 20 ticker/value rows, sums duplicate tickers, divides issuer-described screened value by total value, and leaves unknown evidence separate. Paper Lab: uses yfinance history and a bounded compounding formula. Neither can place orders, access a brokerage, or change holdings.

Run limits: 4 model requests, 4 tool calls, 2,000 total output tokens, and an 850-token response setting. Chat history is capped at six recent turns and 400 characters each. The price universe and date span are bounded in code.

A single research agent is sufficient for the current task. Additional collaborating agents would add cost and harder-to-audit handoffs without solving the main missing input: current constituent-level screening evidence.

04 / Scale and savings

The economics depend on search frequency

Scenario: one user asks 20 research questions per month, half price requests and half news requests. Each type is assumed to cost exactly what the observed example cost. This is a planning assumption, not measured usage across a user population.

A concrete savings lever

Reducing the observed news run from three web searches to one would save approximately $0.02 per news turn before any change in token usage. At 10 news turns per user each month, that is about $0.20 per user, $20 per 100 users, or $2,000 per 10,000 users monthly. It might also miss corroborating sources; quality should be checked before imposing the tighter limit. The app currently permits up to four total tool calls, so this saving is a proposal, not an achieved result.

Other costs and limits

  • Yahoo Finance/yfinance prices have no separately measured API charge in this prototype, but availability and licensing for scaled commercial use need review.
  • Hosting, monitoring, human advisor time, payment processing, taxes, and any Portkey markup are excluded.
  • The reported token totals came from two sample questions. They should not be treated as a stable distribution without more logs.
  • Portfolio and Paper Lab calculations do not call the model, so their incremental model token cost is zero in this implementation.
Measured cost-quality tradeoff: For HLAL over 2025-10-27 to 2026-10-26, the tool received 250 daily closes but sent only the first and last 12 to the model: 1,057 JSON bytes instead of 11,033. This trims the tool payload by about 90%, but omitted the 2026-04-28 close. A separate narrow query recovered that quote ($65.76), adding a tool call. The ticker and one-year limits also reduce breadth.

05 / Safety

Guardrails and a blocked attack

The app handles financial questions and untrusted web results. Plausible failures include a fabricated price, a wrong ticker, a false compliance claim, a prompt injection in search content, leakage of the Portkey key, and an unbounded number of paid tool calls.

07 / Limits and next steps

What the evidence cannot yet support

  1. Constituent screening: The portfolio percentage reflects issuer-described strategy coverage, not a recomputation of current holdings, sector exclusions, debt ratios, or purification amounts. Obtain dated holdings and methodology data; add rule-level results with coverage before calling it a compliance score.
  2. Methodology choice: Shariah screens differ. A future release should show the selected authority or index standard, exact thresholds, date, and any conflicting conclusion.
  3. Security breadth: The agent prices only eight named funds. Unsupported stocks and ambiguous fund names need explicit review; broad stock screening would require vetted fundamentals and business-activity data.
  4. News quality: Search result URLs are surfaced, but not every third-party statement has been independently corroborated. Prefer official issuer and regulator documents for consequential claims.
  5. Client workflow: The About page offers account setup education only. There is no account connection, personalized trade recommendation, credential collection, or order execution.
  6. Deployment and evidence: A temporary clean copy installed dependencies and returned HTTP 200 for all four pages; a dummy parent-folder .env was found. The public repository is published; grader-run confirmation and a real-user trial remain.

Reproduce the prototype

From the repository root, create .venv, install requirements.txt, put PORTKEY_API_KEY in a root or parent-folder .env, run .venv/bin/python app.py, and open http://127.0.0.1:8050. The README gives exact steps. The included portfolio.json is illustrative; no real client holdings or keys are included.
